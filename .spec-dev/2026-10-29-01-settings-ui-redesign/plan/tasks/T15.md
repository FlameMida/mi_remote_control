**步骤 3：写最小实现**

- `SheetScaffold.body`：`VStack(alignment: .leading, spacing: 14)`〔标题区 `HStack(alignment: .top)`：`VStack(alignment: .leading, spacing: 2) { Text(title).font(.headline).lineLimit(2); subtitle 存在时 Text(subtitle).font(.caption).foregroundStyle(.secondary).fixedSize(horizontal: false, vertical: true) }`、`Spacer(minLength: 8)`、`onClose` 非空时 `Button(action: onClose) { Image(systemName: "xmark.circle.fill").foregroundStyle(.secondary) }.buttonStyle(.plain).keyboardShortcut(.cancelAction).help(closeHelp).accessibilityLabel("关闭")`；`content()`；`HStack(spacing: 8) { footer() }`（左侧说明与 `Spacer` 由调用方放，主按钮在最右）〕`.padding(Spacing.sheetPadding).glassSheetBackground()`。宽高不在骨架里定，由各调用方原样保留。
- `HealthCheckSheet`：`SheetScaffold(title: "一键体检与修复", subtitle: nil, onClose: { dismiss() }) { 总结横幅 + 6 项列表（原样） } footer: { Button("重新体检"); Spacer(); [退出并重新打开（原条件、原 help、原 .borderedProminent）]; Button("尝试自动修复") }`，外层 `.frame(width: 480)` 与 `.onAppear` 保留。
