**步骤 3：写最小实现**

- 背景：删去 `.background(Color(nsColor: .windowBackgroundColor))` 及其上方说明注释，改为 `.glassSurface(.panel, in: Rectangle())`；更新注释为「macOS 26 液态玻璃；旧系统与降低透明度时回退为原版不透明系统底色（T01 `.panel` → `.opaque`）」。
- 设备名：`Text(model.displayDeviceName).font(.body.weight(.semibold)).multilineTextAlignment(.leading).fixedSize(horizontal: false, vertical: true)`，与 statusLine 同在 `VStack(alignment: .leading, spacing: 1)` 中，`VStack` 加 `.frame(maxWidth: .infinity, alignment: .leading)`，删除其后的 `Spacer()`（由 frame 撑开），电量环与健康点仍在右侧。
- statusLine：把 `statusLine` 拆为 `statusParts: [String]`（原逻辑不变，`statusLine` 保留为 `statusParts.joined(separator: " · ")` 供其他处使用）；渲染为 `ViewThatFits(in: .horizontal) { Text(statusLine).noWrap(); VStack(alignment: .leading, spacing: 0) { Text(statusParts[0] + " ·").noWrap(); Text(statusParts.dropFirst().joined(separator: " · ")).noWrap() } }`，字体与颜色沿用 `.caption` / `.secondary`；未连接时 parts 为 `["未连接", "长按 主页+返回 配对"]`，暂停为 `["已连接", "已暂停遥控"]`，拼接结果与原字符串逐字相同。
- 其余三段（暂停开关、语音分段、底部按钮）不改结构；`Button("打开设置")`、`Button("一键体检")` 追加 `.noWrap()`。
- 浮动角标：`show(text:)` 中 `.foregroundStyle(.white)` 改为 `.foregroundStyle(.primary)`，`.background(Capsule().fill(Color.black.opacity(0.72)))` 改为 `.glassSurface(.overlay, in: Capsule())`，外加 `.overlay(Capsule().stroke(Color(nsColor: .separatorColor), lineWidth: 1))` 与 HintBar 一致；面板创建、位置、点穿、`flash` 时长 1.2 s 与 `refresh` 逻辑不动。
- `StatusItemController` 的图标、着色优先级、标题角标、悬停提示、`buildMenu`、点击路由一律不动。

**风险**：
- `NSPopover` 自带材质，SwiftUI 内容再叠液态玻璃时可能出现双层效果；如在 macOS 26 实机上发现，可只在 `.liquidGlass` 分支把 popover 的 `appearance` 设为跟随系统并去掉内容层底色。这需要改 `StatusItemController` 类，超出本票范围，届时回到计划层面裁决。
- 原注释说明不透明是为避免浅色下采样桌面显脏；`.material` 分支不适用于 `.panel`（T01 已规定回退为 `.opaque`），故旧系统外观与原版一致。
- statusLine 在层激活时为「已连接 · App 控制 · <App>」，换行时第二行为「App 控制 · <App>」整体不拆；App 名极长时第二行会被 `noWrap` 撑出 300 宽，需在第二行改用 `.lineLimit(1).truncationMode(.tail)`，人工核对时用长名 App 验证。
- 角标原为黑底白字，在任何桌面上都高对比；改为玻璃后对比度取决于身后内容。`.overlay` 在 macOS 14–15 回退为 `.material`（T01），浅色桌面上仍可读；若实测对比度不足，可在 `.material` 分支加一层 `Color(nsColor: .windowBackgroundColor).opacity(0.6)`。
