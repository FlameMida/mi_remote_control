**步骤 3：写最小实现**

- `StatusIssue`：按断言实现；`bannerKind`：degraded → `.error`，permission / disconnected → `.warning`，paused → `.info`。行图标（线条 SF Symbol，非 emoji）：permission `exclamationmark.triangle`，degraded `xmark.octagon`（红），disconnected `antenna.radiowaves.left.and.right.slash`。
- `PermissionStatus.refresh()`：输入监控未授权 → `"输入监控"`，否则辅助功能未授权 → `"辅助功能"`，否则 `nil`；`init` 中调用一次并订阅 `NSApplication.didBecomeActiveNotification` 再刷新。
- `RootView`：`@StateObject private var permissions = PermissionStatus()`；`issue = StatusIssue.current(degraded: model.degraded, missingPermission: permissions.missing, connected: model.connected, suspended: model.remoteSuspended)`；整体 `.environment(\.statusIssue, issue).environment(\.statusFix, fix)`；`fix`：degraded / permission → `showHealthCheck = true`；disconnected → `onboardingStep = 2; showOnboarding = true`；paused 无动作。GeneralPage 的「重新运行首次启动引导」与启动时自动弹引导前把 `onboardingStep = 0`。
- `SidebarIssueRow`：读环境值，`sidebarRow` 非空时显示「图标 + rowText + 右侧 rowAction」整行按钮（`.buttonStyle(.plain)`，文字 `.noWrap()`），点击调用 `statusFix`。
- `PageStatusBanner(page:)`：`StatusIssue.banner(for: page, issue: statusIssue)` 非空时渲染 `StatusBanner(kind: bannerKind, title: bannerTitle + " · " + bannerDetail（标题加粗）, actionTitle: bannerAction, action: { statusFix(issue) })`；四页各在 `PageHeader` 后插入 `PageStatusBanner(page: .<页>)`。
