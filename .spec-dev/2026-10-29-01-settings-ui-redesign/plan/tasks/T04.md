### 任务 4：遥控器型号判定与设备名回退

**交付与验证**：新增纯函数 `RemoteModel`，按「已连接 + 生效 VID/PID」判定是否为 MI RC 2 Pro；`AppModel` 暴露只读 `remoteModel` 与 `displayDeviceName`。示意图切换（T08）、侧栏头（T05）、菜单栏状态卡（T17）消费。不改 `HIDEngine`、`RemoteIdentity`、`noteConnection`。

**覆盖**（spec 542–586 行「MI RC 2 Pro 专用遥控器示意图」判定规则）：
- Scenario「连接的是 RC 2 Pro」：0x2717 / 0x32B8 + 已连接 → `.rc2Pro`，设备名回退「MI RC 2 Pro」。
- Scenario「其他型号或未识别」：其他 VID/PID → `.generic`，设备名回退「MI RC」。
- Scenario「连接 / 断开时实时切换且不位移」：断开 → `.generic`（「未连接时一律用通用示意图」）；数据侧。
- 侧栏头第 2 行回退规则（spec 527 行）。

**文件**：
- 创建：`Sources/MiRemote/UI/RemoteModel.swift`
- 修改：`Sources/MiRemote/UI/AppModel.swift`（在 `@Published var deviceName`（228 行）附近新增两个计算属性；不动 `noteConnection` 与 `saveConfig`）
- 测试：`Sources/MiRemote/App/SelfTest.swift`（末尾 UI 重设计块）

**接口**：
- 消费：`RemoteIdentity.vendorID / productID / defaultVendorID / defaultProductID`（`App/Contracts.swift:8–26`，只读）；`AppModel.connected`、`deviceName`。
- 产出：
  - `enum RemoteModel: Equatable { case rc2Pro, generic }`
  - `static func resolve(connected: Bool, vendorID: Int, productID: Int) -> RemoteModel` —— `connected && vendorID == 0x2717 && productID == 0x32B8` 为 `.rc2Pro`，否则 `.generic`。
  - `static func fallbackName(vendorID: Int, productID: Int) -> String` —— 生效 VID/PID 为 RC 2 Pro 时「MI RC 2 Pro」，否则「MI RC」（与 `ATVVBridge.swift:546` 的回退一致）。按配置的型号而非连接状态取名，使未连接时侧栏与菜单栏仍显示原版默认「MI RC 2 Pro」（spec 菜单栏「设备名（默认「MI RC 2 Pro」）」）。
  - `static func selfCheck() -> Bool`
  - `AppModel.remoteModel: RemoteModel { RemoteModel.resolve(connected: connected, vendorID: RemoteIdentity.vendorID, productID: RemoteIdentity.productID) }`
  - `AppModel.displayDeviceName: String { deviceName ?? RemoteModel.fallbackName(vendorID: RemoteIdentity.vendorID, productID: RemoteIdentity.productID) }`
  两个属性随 `connected` / `deviceName`（均为 `@Published`）变化自动刷新视图；`RemoteIdentity` 只在启动早期配置一次，不需要发布。

**步骤 3：写最小实现**

**风险**：
- `connected` 来自 ATVV 能力协商（BLE），而 VID/PID 是 HID 匹配条件；两者在极少数情况下不同步（BLE 已连而 HID 尚未匹配）。按 spec 判定规则只看 `connected`，可接受；验收矩阵 721 / 725 行实机核对。
- `RemoteIdentity.vendorID` 为 `nonisolated(unsafe)` 静态量，只在启动早期写一次，主线程读取安全（`Contracts.swift:6–7` 注释）。
