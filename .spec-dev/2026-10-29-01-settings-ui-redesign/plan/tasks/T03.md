**步骤 3：写最小实现**

- `resolve`：取 `own = config.profiles[profile]?[key.rawValue]` 中该槽位的值；`profile == "global"`：有值 → `.appOverride`，否则 `.unset`。App profile：`own` 有值 → `.appOverride`；否则取 global 同槽位，有值 → `.inherited`，否则 `.unset`。槽位取值：tap / hold / double 直接字段；`gesture(d)` → `gesture?[d]`；`layer(n)` → `layers?["\(n)"]`。
- 与 `MappingDetailResolver.binding`（`UI/MappingDetailView.swift:5–27`）的合并语义一致（逐槽位覆盖、字典逐键合并）；不改该函数。
- `removingOverride`：只对非 global profile 删除该槽位；`gesture` / `layers` 空字典置 `nil`；整条绑定五个字段全空时从 profile 中移除该键；profile 变空时保留空字典（不删除场景本身，保证场景列表不变）。
- `restoreInherited`：`config = SlotResolver.removingOverride(config: config, profile: currentProfile, key: key, slot: slot); saveConfig()`（`saveConfig` 已负责热加载与 `savedTick += 1`，即「已保存」）。
- `SourceTag`：`profile == "global"` 或 `source == .unset` 时为 `EmptyView`；`.appOverride` → 文本「App 覆盖」强调色胶囊；`.inherited` → 「继承全局」次要色虚线描边胶囊；字号 `.caption2`，`.lineLimit(1).fixedSize()`；`accessibilityLabel` 为同一文本。
- 覆盖计数沿用现有按键条目计数（ProfilePage「已覆盖 n 个键」），恢复移除空条目即实现「减 1」；不新增计数逻辑。
