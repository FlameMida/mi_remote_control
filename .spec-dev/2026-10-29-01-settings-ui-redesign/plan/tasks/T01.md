**交付与验证**：`DesignSystem.swift` 成为玻璃判断的唯一落点；外观选择规则为纯函数并有 selfCheck；提供页内横幅、短标签不断行修饰器与可带右侧附件的标题区。本票只建原语，不改任何页面（页面由后续票消费）。

**覆盖**：
- Requirement「macOS 26 液态玻璃与回退」：规则部分（三种外观、降低透明度优先、集中一处）；Scenario「液态玻璃回退（旧系统）」「液态玻璃回退（降低透明度）」的判定逻辑（视觉部分由 T15–T18、T20 验收）。
- Requirement「短标签不断行与标题区排版」：提供 `noWrap()` 与标题行附件位。
- spec「错误与边界」：`StatusBanner` 统一呈现。

**步骤 1：写失败测试**

先在 `DesignSystem.swift` 末尾加骨架：两个枚举、`GlassSurface.appearance` 恒返回 `.material`、`glassAvailable` 恒 `false`、`selfCheck()` 调用下列断言逻辑并返回结果；`glassSurface` / `glassSheetBackground` / `noWrap` 暂时原样返回 `self`；`StatusBanner` 先只渲染 `Text(title)`；`PageHeader` 改为泛型并加 `EmptyView` 便捷 init。
`selfCheck()` 断言（每条单独计数，任一失败返回 false）：
- `appearance(kind: .overlay, glassAvailable: true, reduceTransparency: false) == .liquidGlass`
- `appearance(kind: .sheet, glassAvailable: false, reduceTransparency: false) == .material`
- `appearance(kind: .panel, glassAvailable: false, reduceTransparency: false) == .opaque`（菜单栏面板回退时保持原版不透明，spec 菜单栏 Requirement「回退时不透明」）
- 三种 kind 在 `reduceTransparency: true` 时无论 `glassAvailable` 都为 `.opaque`

**步骤 3：写最小实现**

- `appearance`：`reduceTransparency` → `.opaque`；否则 `glassAvailable` → `.liquidGlass`；否则 `kind == .panel ? .opaque : .material`。
- `glassAvailable`：`#if compiler(>=6.2)` 内 `if #available(macOS 26, *) { return true }`；其余返回 `false`。
- `glassSurface(_:in:)`：内部用 `@Environment(\.accessibilityReduceTransparency)` 的私有 ViewModifier 计算外观；`.liquidGlass` → `#if compiler(>=6.2)` + `#available(macOS 26, *)` 下 `.glassEffect(.regular, in: shape)`；`.material` → `.background(.regularMaterial, in: shape)` + 现有阴影；`.opaque` → `.background(Color(nsColor: .windowBackgroundColor), in: shape)` + `shape.stroke(Color(nsColor: .separatorColor))`。三种分支只改背景，不改 padding / frame（命中区一致）。
- `glassSheetBackground()`：`.liquidGlass` 不加修饰（系统 sheet 自带玻璃）；`.material` → `.presentationBackground(.regularMaterial)`；`.opaque` → `.presentationBackground(Color(nsColor: .windowBackgroundColor))`。
- `noWrap()`：`.lineLimit(1).fixedSize(horizontal: true, vertical: false)`。
- `StatusBanner`：HStack〔线条 SF Symbol（warning `exclamationmark.triangle`、error `xmark.octagon`、info `info.circle`，不用 `.fill` 以符合「线条警示图标」）+ 标题（可换行，左缘对齐文字列）+ 可选按钮（`.noWrap()`）〕，背景 `glassSurface(.overlay, in: RoundedRectangle(cornerRadius: Radius.card))` 叠一层 kind 对应的低不透明度色。
- `PageHeader`：标题行 `HStack(alignment: .firstTextBaseline, spacing: 8) { Text(title).font(.title2.bold()).noWrap(); accessory() }`（不内置 Spacer，由调用方在 accessory 中自行放置，便于「已保存」紧跟标题、按钮靠右），副标题单独一行占满宽度（spec「页面标题区 SHALL 让副标题占满整行宽度」）。
