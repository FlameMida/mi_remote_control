## 新问题（每个附默认值，未回答即按默认）

- **N1** 映射页示意图上方的「示意图显示」分段（短按 / 快捷控制 / App 控制 / App 导航）只用于切换标注显示哪一层，不改变编辑对象。要保留吗？
  - **默认**：保留，只作预览用途。
- **N2** 侧栏收起后的形态：完全隐藏（`NavigationSplitView` 惯例），还是保留一列仅图标栏？收起状态是否跨启动记住？
  - **默认**：完全隐藏；只在本次进程内记住，重启后恢复为展开。
- **N3** 方向键、返回键、OK 键的短按槽位不再锁定，也不加图标：照原 UI 显示并可编辑，只在槽位下方加一行纯文字说明（依据 `MappingEngine.fireTap` 基础状态处理与 `GeneralPage.swift:102`）。说明写明：基础状态下方向键为光标键、返回为删除（Delete）、OK 为回车（Return，仅 App 场景的明确设置可替代）；这里的短按设置只在第二功能模式下（且该模式没有单独设置时）生效。旧配置里已有的值（例如全局 OK 短按 = Spotlight）照常显示、不改写配置、不额外弹警告。这样可以吗？
  - **默认**：可以。文案见 spec「基础状态短按的文字说明」。
- **N4** 菜单栏状态面板原版刻意使用不透明背景（`StatusItemController.swift:240`），重设计在 macOS 26 上改用液态玻璃。保留玻璃吗？
  - **默认**：保留玻璃（与其他浮层一致），「降低透明度」与 macOS 14–15 回退到原不透明背景。
- **N5** 型号识别与画法细节：原版没有运行时型号识别，只有 HID 匹配用的 VID/PID（`Contracts.swift:5-10`，可被 config 覆盖，`Contracts.swift:213-216`）与 BLE 外设名（`ATVVBridge.swift:546`，用户可改名）。另外，照片中电源 / 语音键是银色键面 + 细黑描边，并非黑键；照片透视校正后机身高:宽实测 4.35，官方尺寸 158 x 35 mm 为 4.51。
  - **默认**：以生效的 VID/PID == 0x2717 / 0x32B8 且已连接判定为 RC 2 Pro（实施时可在 `HIDEngine.handleDeviceMatched` 读实际设备的 VID/PID 再确认）；电源 / 语音按照片画为银色键；机身比例用官方 4.51，纵向位置按此标定。
